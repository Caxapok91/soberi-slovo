# Собери слово

Игра для телефона: соединяй буквы плиток и отгадывай спрятанные слова —
аналог «Хитрое слово: слова из букв».

Чистый HTML/CSS/JS, без сборки и зависимостей. После первого запуска
работает без интернета.

## Как запустить

Нужен любой статический сервер (с `file://` не работают service worker
и локальное хранилище):

```bash
# удобный сервер без кэширования — для разработки
python tools/dev_server.py 8000

# или стандартный
python -m http.server 8000
```

Сервер слушает все интерфейсы и печатает адрес в консоли:

```
Компьютер: http://127.0.0.1:8000
Телефон:   http://192.168.1.4:8000
```

Открывай на телефоне адрес из второй строки (нужна одна Wi-Fi сеть).
Если порт занят или телефон не открывает страницу — проверь брандмауэр
и разреши Python входящие подключения.

Установка на телефон: Chrome Android → меню → «Установить приложение».

### Про офлайн и установку

Игра — обычные HTML/CSS/JS, поэтому на телефоне с http:// всё работает,
кроме одного: браузеры разрешают service worker (оффлайн-режим и
установка PWA) только на **https** или на `localhost`.

Если нужен полноценный офлайн и иконка приложения — залей папку на любой
статический хостинг с https (GitHub Pages, Netlify, Vercel, свой сервер
с сертификатом). Ничего настраивать не нужно: `manifest.json` и `sw.js`
уже готовы, игра запустится на весь экран и будет работать без сети.

На http:// по локальной сети игра запускается как обычная страница —
всё, кроме офлайна и установки.

### Если выложил новую версию в GitHub

Прогресс игроков **не пострадает**: он лежит в `localStorage` на устройстве
и привязан к адресу сайта, а не к файлам в репозитории. Замена файлов
на GitHub его не касается.

Но есть два правила, без которых обновление может не дойти:

1. **Подними версию кэша в `sw.js`** — строка `const CACHE = 'soberi-slovo-v6'`.
   Старый кэш удалится сам при активации новой версии worker'а.
2. **Не меняй ключ `SAVE_KEY`** в `js/game.js` (`soberi_slovo_save_v3`).
   Это имя хранилища: переименуешь — и весь прогресс игроков пропадёт.

Код и оформление отдаются сначала из сети, кэш — только если сеть недоступна,
поэтому правки обычно видны сразу. Если у кого-то осталась старая версия —
достаточно обновить страницу пару раз или закрыть и открыть вкладку заново.

## Как играть

- **Сверху кроссворд с настоящими пересечениями.** Слова ложатся в сетку по
  рядам и столбцам и цепляются друг за друга общей буквой.
- **Главная механика — подсказка через пересечение.** Отгадал слово — оно
  открылось зелёным, а в пересекающихся словах появились **жёлтые буквы**.
  Это настоящая подсказка для следующего слова, а не отдельная кнопка.
- **Слева столбик с бонусами** — слова, собранные из тех же букв, но не
  загаданные. Задания не показываются: иначе игрок читает их вместо того,
  чтобы искать. Пока бонусов нет, столбик свёрнут и не отнимает место.
- **Снизу круг с буквами.** Тапаешь по буквам — они складываются в слово.
  Когда слово найдено, круг мигает и становится меньше.
- **Слотов в поле ввода столько, сколько букв в самом длинном слове
  уровня.** Их число не меняется всю игру — буквы не «прыгают» под пальцем.
- Пока набираешь слово, **подходящие ряды подсвечиваются в сетке** — видно,
  куда вписывать.
- Если набранное слово — начало более длинного задания, игра подождёт:
  «стол» и «столб» не путаются, пока не допечатаешь до конца.
- Из тех же букв собираются другие слова — они идут в «Бонусы»,
  дают монеты и **больше не засчитываются повторно**: при повторном вводе
  игра сообщает «уже введено».
- Падежные формы в бонусы не идут: «село» засчитается, а «сел» — нет.
- Буквы можно использовать сколько угодно раз. По мере нахождения слов
  буквы с круга убираются — круг упрощается.
- **Буква** (50 ★) подсказывает следующую букву настоящего слова уровня
  и ставит её на своё место. **Слово** (150 ★) вписывает задание целиком.
  Чем меньше подсказок, тем больше звёзд за уровень (3 / 2 / 1).

## Сложности

| Сложность | Слов | Длина |
|-----------|------|-------|
| Легко     | 4    | 3–4   |
| Средняя   | 5    | 4–6   |
| Сложно    | 5    | 5–6   |

Длины ограничены словарём: в нём только начальные формы от 3 до 6 букв.
Настройки сложности живут в одном месте — `DIFFICULTY` в `js/levels.js`,
подписи в окне выбора берутся оттуда же, поэтому цифры не расходятся.

## Структура

```
index.html            разметка экранов
css/style.css         оформление и адаптив под телефон
js/words.js           словарь (генерируется, руками не править)
js/levels.js          сложности, подбор слов, раскладка кроссворда

tools/build_words.py  пересборка словаря

tools/make_icons.py   генерация иконок
```

## Словарь

Задания собираются из слов в **начальной форме** — «стол», «кот», «море»,
а не «стола», «котов», «морей». Такие слова человек легко подбирает глазами,
и в кроссворде они выглядят естественно.

Отбор (`tools/build_words.py`) идёт в несколько шагов:

1. Из корпуса (`wordfreq`) берутся слова, которые встречаются **сами**
   в начальной форме. Так уходят обрывки форм: «гот», «кий», «пля» не
   существуют как отдельные слова, в отличие от «стол» и «кот».
2. Слово отбрасывается, если при каком-либо разборе оно оказывается
   формой другого слова: «тура» = мн. ч. «тур», «зала» = род. п. «зал».
3. Отсекаются имена собственные, геонимы, сокращения, новостная лексика,
   интернет-шум и нецензурные слова.
4. Считается, сколько разных словоформ есть у слова. У настоящего слова
   их много («стол», «стола», «столу», «столом»), у транслитераций
   («уокер», «логан») — только сама форма.
5. Остаются начальные формы от 3 до 6 букв: **4 552 слова**
   (3 буквы — 283, 4 — 723, 5 — 1 521, 6 — 2 025).

Дальше словарь проходит ручную чистку: `tools/clean_words.py` убирает
транслитерации («фелпс», «инион»), иностранные фамилии и топонимы
(«мистер», «таджик», «ассанж»), технические термины и опечатки.
Отсев идёт точным списком, а не эвристиками: правило «три согласных
подряд» выбросило бы нормальные слова «есть», «дождь», «жизнь».

```bash
pip install wordfreq pymorphy3
python tools/build_words.py     # пересобрать словарь из корпуса
python tools/clean_words.py     # убрать мусор
```

## Как генерируется уровень

1. Подбираются слова нужной длины по сложности; уже использованные
   исключаются, чтобы уровни не повторялись.
2. Порядок укладки в сетку считается отдельно от порядка показа: первыми
   кладутся слова, у которых больше всего общих букв с остальными. Слово,
   которому не с чем пересечься, поставленное рано, заняло бы место и
   закрыло его для других — поэтому уходит в конец.
3. Каждое слово кладётся по горизонтали или по вертикали и цепляется за уже
   положенное общей буквой. Правила — как в обычном кроссворде: буквы на
   пересечении совпадают, рядом с буквой не стоит буква чужого слова,
   перед началом и после конца — пустая клетка.
4. Полностью пустые ряды и столбцы вырезаются, но только если это не
   склеит два слова в ряд, — иначе сетка выглядела бы разорванной.
5. Пробуется несколько порядков укладки и направлений первого слова;
   выбирается тот, где больше пересечений и плотнее сетка.
6. На круг выносятся буквы ещё ненайденных слов. По мере игры ненайденных
   слов становится меньше, круг упрощается и мигает.

Проверено на 2000 уровнях: ни одного неверного пересечения, в среднем
2.1–3.5 клетки-пересечения на уровень (в зависимости от сложности),
вовсе без пересечений не остаётся ни одного уровня.

Раскладка детерминирована: одни и те же слова всегда дают одну и ту же
сетку, поэтому после выхода в меню поле остаётся тем же. На узких
экранах (от 320×568) кроссворд может прокручиваться, клетки не
уменьшаются ниже читаемого размера.
