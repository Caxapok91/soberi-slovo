# Собери слово

Игра для телефона: соединяй буквы плиток и отгадывай спрятанные слова — аналог «Хитрое слово: слова из букв».

Чистый HTML/CSS/JS, без сборки и зависимостей. После первого запуска работает без интернета (PWA).

### Управление с телефона:
- Тапать по буквам на круге для набора слова
- Слово авто-подставляется после паузы (без кнопки ✓)
- Подсказка (🔍) — тратит 50 монет, добавляет букву
- Сolve (💡) — тратит 150 монет, раскрывает слово
- Бонусы получаются из тех же букв, что и задания
- Не повторяйте уже введенные слова — будет сообщение «уже введено»

## 📱 Как играть

- **Сверху пустой кроссворд.** Сколько белых клеток в ряду — столько букв в слове.
- **Слева столбик со словами:** «Задания» (найденные подсвечены галочкой) и «Бонусы» — слова из тех же букв, что ты уже нашёл. Столбик сворачивается стрелкой, когда мешает.
- **Снизу круг с буквами.** Тапай по буквам — они складываются в слово.
- **Слотов в поле ввода ровно столько, сколько букв в самом коротшем ненайденном слове** — сразу видно минимальную длину. Если набираешь длиннее, слоты добавляются сами.
- **Слово совпало с заданием — сразу встаёт в кроссворд зелёным.** Галочку нажимать не нужно.
- **Из тех же букв собираются другие слова** — они идут в «Бонусы», дают монеты и **больше не засчитываются повторно**: при повторном вводе игра сообщает «уже введено».
- **Падежные формы в бонусы не идут:** «село» засчитается, а «сел» — нет.
- **Буквы можно использовать сколько угодно раз.** По мере нахождения слов буквы с круга убираются — круг упрощается.
- **Подсказка (первая буква) и «показать слово»** — платные функции (50 и 150 монет соответственно), но за уровень с ними будет меньше звёзд (3 / 2 / 1).

## 📚 Словарь

Задания собираются из слов в **начальной форме** — «стол», «кот», «море», а не «стола», «котов», «морей». Такие слова человек легко подбирает глазами, и в кроссворде они выглядят естественно.

Отбор (`tools/build_words.py`) идёт в несколько шагов:
1. Из корпуса (`wordfreq`) берутся слова, которые встречаются **сами** в начальной форме. Так уходят обрывки форм: «гот», «кий», «пля» не существуют как отдельные слова, в отличие от «стол», «кот», «море».
2. Слово отбрасывается, если при каком-либо разборе оно оказывается формой другого слова: «тура» = мн. ч. «тур», «зала» = род. п. «зал».
3. Отсекаются имена собственные, геонимы, сокращения, новостная лексика, интернет-шум и нецензурные слова.
4. Считается, сколько разных словоформ есть у слова. У настоящего слова их много («стол», «стола», «столу», «столом»), у транслитераций («уокер», «логан») — только сама форма.
5. Остаются 4 601 начальных форм и 20 000 их словоформ. Задания составляются из начальных форм, а падежные формы («столы», «столом») принимаются как бонус — игрок не должен думать, что ошибся.

## Как генерируется уровень

1. Подбираются слова нужной длины по сложности; уже использованные исключаются, чтобы уровни не повторялись.
2. Слова сортируются по длине — в кроссворде ряды выглядят разными.
3. Каждому слову отводится ряд из пустых клеток нужной длины, края закрыты «заглушками» — получается вид кроссворда. Ряды смещены друг относительно друга, как в настоящем кроссворде.
4. На круг выносятся буквы ещё ненайденных слов. По мере игры ненайденных слов становится меньше, круг упрощается.

Размер клеток и букв на круге считается под экран: расстояние между соседними буквами всегда не меньше их размера, поэтому на круге ничего не налезает друг на друга — проверено на экранах от 320×568 до 414×896. Уровень воспроизводим по ключу (сложность + номер), поэтому после выхода в меню поле остаётся тем же.

## 📱 Офлайн и PWA

- **На GitHub Pages (https):** Всё работает: офлайн-режим, установка в приложение, сохранение прогреса.
- **По http:// по локальной сети:** Играется как обычная страница, но офлайн и установка PWA не работают (требуются https).
- **Как установить на Android:** Откройте игру, нажмите кнопку меню → «Установить приложение» (или иконка в адресной строке).

## 📱 Управление

- **Тапать по буквам** на круге для набора слова
- **Авто-подставление:** Слово подставляется после короткой паузы (без нажатия ✓)
- **Подсказка (🔍):** Тратит 50 монет, добавляет первую нужную букву в набор
- **Solve (💡):** Тратит 150 монет, раскрывает полное слово с анимацией
- **Бонусные слова:** Из тех же букв, что и задания — идут в сторону, дают монеты, блокируются повторным вводом
- **Брандмауэр:** Если телефон не открывает страницу — проверь разрешения Python на компьютере
