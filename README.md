# Собери слово

Игра для телефона: соединяй буквы плиток и отгадывай спрятанные слова —
аналог «Хитрое слово: слова из букв».

Чистый HTML/CSS/JS, без сборки и зависимостей. После первого запуска
работает без интернета.

## Как запустить

Нужен любой статический сервер (с `file://` не работают service worker
и локальное хранилище):

```bash
# удобный сервер без кэширования — для разработки
python tools/dev_server.py 8000

# или стандартный
python -m http.server 8000
```

Сервер слушает все интерфейсы и печатает адрес в консоли:

```
Компьютер: http://127.0.0.1:8000
Телефон:   http://192.168.1.4:8000
```

Открывай на телефоне адрес из второй строки (нужна одна Wi-Fi сеть).
Если порт занят или телефон не открывает страницу — проверь брандмауэр
и разреши Python входящие подключения.

Установка на телефон: Chrome Android → меню → «Установить приложение».

### Про офлайн и установку

Игра — обычные HTML/CSS/JS, поэтому на телефоне с http:// всё работает,
кроме одного: браузеры разрешают service worker (оффлайн-режим и
установка PWA) только на **https** или на `localhost`.

Если нужен полноценный офлайн и иконка приложения — залей папку на любой
статический хостинг с https (GitHub Pages, Netlify, Vercel, свой сервер
с сертификатом). Ничего настраивать не нужно: `manifest.json` и `sw.js`
уже готовы, игра запустится на весь экран и будет работать без сети.

На http:// по локальной сети игра запускается как обычная страница —
всё, кроме офлайна и установки.

## Как играть

- **Сверху пустой кроссворд.** Сколько белых клеток в ряду — столько букв в слове.
- **Слева столбик со словами:** «Задания» (найденные подсвечены галочкой) и
  «Бонусы» — слова, собранные из тех же букв, но не загаданные.
  Столбик сворачивается стрелкой, когда мешает.
- **Снизу круг с буквами.** Тапаешь по буквам — они складываются в слово.
- **Слотов в поле ввода ровно столько, сколько букв в самом коротком
  ненайденном слове** — сразу видно минимальную длину. Если набираешь
  длиннее, слоты добавляются сами.
- Слово совпало с заданием — **сразу встаёт в кроссворд** зелёным.
  Галочку нажимать не нужно.
- Из тех же букв собираются другие слова — они идут в «Бонусы»,
  дают монеты и **больше не засчитываются повторно**: при повторном вводе
  игра сообщает «уже введено».
- Падежные формы в бонусы не идут: «село» засчитается, а «сел» — нет.
- Буквы можно использовать сколько угодно раз. По мере нахождения слов
  буквы с круга убираются — круг упрощается.
- Подсказка (первая буква) и «показать слово» — **бесплатные**,
  но за уровень с ними будет меньше звёзд (3 / 2 / 1).

## Словарь

Задания собираются из слов в **начальной форме** — «стол», «кот», «море»,
а не «стола», «котов», «морей». Такие слова человек легко подбирает глазами,
и в кроссворде они выглядят естественно.

Отбор (`tools/build_words.py`) идёт в несколько шагов:

1. Из корпуса (`wordfreq`) берутся слова, которые встречаются **сами**
   в начальной форме. Так уходят обрывки форм: «гот», «кий», «пля» не
   существуют как отдельные слова, в отличие от «стол» и «кот».
2. Слово отбрасывается, если при каком-либо разборе оно оказывается
   формой другого слова: «тура» = мн. ч. «тур», «зала» = род. п. «зал».
3. Отсекаются имена собственные, геонимы, сокращения, новостная лексика,
   интернет-шум и нецензурные слова.
4. Считается, сколько разных словоформ есть у слова. У настоящего слова
   их много («стол», «стола», «столу», «столом»), у транслитераций
   («уокер», «логан») — только сама форма.
5. Остаются 6 195 начальных форм и 20 000 их словоформ. Задания
   составляются из начальных форм, а падежные формы («столы», «столом»)
   принимаются как бонус — игрок не должен думать, что ошибся.

```bash
pip install wordfreq pymorphy3
python tools/build_words.py
```

## Как генерируется уровень

1. Подбираются слова нужной длины по сложности; уже использованные
   исключаются, чтобы уровни не повторялись.
2. Слова сортируются по длине — в кроссворде ряды выглядят разными.
3. Каждому слову отводится ряд из пустых клеток нужной длины, края
   закрыты «заглушками» — получается вид кроссворда. Ряды смещены
   друг относительно друга, как в настоящем кроссворде.
4. На круг выносятся буквы ещё ненайденных слов. По мере игры ненайденных
   слов становится меньше, круг упрощается.

Размер клеток и букв на круге считается под экран: расстояние между
соседними буквами всегда не меньше их размера, поэтому на круге ничего
не налезает друг на друга — проверено на экранах от 320×568 до 414×896.
Уровень воспроизводим по ключу (сложность + номер), поэтому после выхода
в меню поле остаётся тем же.
